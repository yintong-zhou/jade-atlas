# About page from the CV: plan

Date: 2026-11-16. Branch `feat/public-redesign`. Claude plans and reviews, Codex executes one task at a time (no network, no parallel runs).

## Goal

Make the About page carry the owner's real career (from the CV) and fix its spacing. Copy is already written in `PROFILE.md` (About section); the strings below are final, copy them verbatim.

## Findings that shape the work

- There is no API yet. In dev, `frontend/src/shared/api/sampleData.ts` feeds the page ("Sample ..." rows); in production the career sections are empty. Keep that gate. Do not make the data ship statically (scope change, owner decides).
- `brand-guidelines.md`: `min-height: 100svh` is for Home sections only. Other sections use `section-pad` (top `--padt`, bottom `--padb`). The current About intro has `min-h-[calc(100svh-var(--header-height))]`, which leaves about 250px of dead space under the text and an empty left column.
- Skills and Education sit in one muted band but each has its own `section-pad`, so there is a double gap between them.
- Privacy: the CV file holds a phone number and a street-level town. Neither may appear anywhere in the repo. The location is "Milan".

## Rules for every task

- Do not touch: `heroScene.ts`, `heroTimeline.ts`, `blackHoleLayer.ts`, `HeroSequence.tsx`, `vendor/`, the `rock-*.webp` files.
- Components hold no copy: every visible string lives in `frontend/src/shared/texts.ts`.
- Tokens and utilities from `frontend/src/index.css` only; spacing on the 4px scale (4, 8, 12, 16, 24, 32, 48, 64, 96, 128). No shadows, gradients or blur on content. Glass only on controls.
- Format with `npx prettier --no-semi --single-quote --print-width 120 --write <file>` (offline: use the cached copy).
- Finish with, from `frontend/`: `npm.cmd run lint`, `npm.cmd run build`, `npm.cmd run test`. Report the output. Do not commit.
- Python is not installed. Do not add dependencies.
